# FPGA AI Suite native-Windows installation

Date: 2026-08-19 (America/Chicago)

FPGA AI Suite 2026.1.1 is installed and verified on native Windows. No WSL or
Docker was used. No separate example design was downloaded.

## Installed components

- FPGA AI Suite: `C:\altera_pro\2026.1.1`, registered as version 26.1.1.130.
- DLA compiler: `2026.1.1+b17` (`build_version.txt` is `2026.1.1/17`).
- OpenVINO runtime: `C:\altera_pro\openvino_2025.4.0`.
- Existing Quartus Pro root: `C:\altera_pro\26.1\quartus`.
- The installed AI Suite license feature is present and valid through
  2026-10-22.

Use `scripts\ai_suite_env.cmd` from a Command Prompt to configure OpenVINO,
FPGA AI Suite, and `QUARTUS_ROOTDIR` in the required order.

## Verification

After both environment scripts were loaded, `dla_compiler --version` returned
`2026.1.1+b17` with exit code 0.

The official bundled Agilex-3 architecture
`AGX3_Small_Softmax.arch` was used only for an installation sanity check:

```text
dla_compiler --fanalyze-area --march AGX3_Small_Softmax.arch
ALMs:        23610
ALUTs:       27285
DSPs:        42
Registers:   68752
M20Ks:       190
Memory ALMs: 2629
```

The command exited 0 in `1.5573449` seconds. Its transient
`compiled_model_dir` output was removed from the Git workspace after the
numeric results were copied here and moved to the recoverable task-temporary
path `C:\Temp\codex-fpga-ai-area-verification`; it can also be regenerated by
rerunning the command. This check validates the compiler installation and
Agilex-3 architecture support. It does not claim that ResNet-8 has been
compiled or accelerated.

A final GPT-5.6 SOL read-only audit independently verified the registry entry,
environment script, compiler/build versions, local artifact hashes and
signatures, area-report values, Windows limitation, HyperRAM constraint, and
repository consistency. It returned GO in `456.3888297` seconds. The exact
license expiry remains supported by the earlier sanitized license audit; the
final pass confirmed the feature but did not re-emit the expiry in parseable
output.

Native Windows RTL simulation is not supported in FPGA AI Suite 2026.1.1.
Future IP/example generation must use `--skip-sim-env`; Quartus compilation and
hardware execution remain available on Windows.

## Installation incident disclosure

The older qinst GUI was briefly launched while testing its component support.
Its default selection immediately started a 21.05 GB Quartus/device download.
It was stopped at 5%. Several partial/current-timestamp `.qdz` files were
observed under `C:\Users\tcove\Downloads\altera_pro_26.1`. Because that folder
may contain user-owned material, none of those files were deleted or modified
after the process was stopped. The subsequent supported CLI installation
downloaded only FPGA AI Suite into a task-specific temporary directory.

## Scope

The installed toolchain enables the intended FPGA AI Suite accelerator path.
The repository's existing Nios V/m run is only a scalar smoke baseline. The
remaining work is to compile the pinned ResNet-8 model, generate accelerator IP
with `--skip-sim-env`, integrate it into the Arrow AXC3000 derivative, and run
the generated accelerator on the connected board. HyperRAM must remain unused
or clocked at no more than 150 MHz.
